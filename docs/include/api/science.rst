Science Module
========================

This is our module for geometric utilities and scientific useful computations. It provides 
a set of tools for manipulation of three-dimensional representations used in our :doc:`spangler`, 
and geometrical computations for modelling a planetary transit implemented in :any:`system.System.update_Transit`.
