Spangler Module
========

This module provides the :class:`~pryngles.spangler.Spangler` class for
sampling and discretizing the surfaces of astrophysical bodies into facets
(`Spangles`) and computing their geometric, visibility, intersection, and
illumination properties in multiple reference frames.
